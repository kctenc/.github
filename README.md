# GitHub Projects 코멘트 작성 가이드

GitHub Projects에서는 업무 항목(Task/Issue)별로 **진행 상황, 요청사항, 확인 내용 등을 코멘트로 남길 수 있습니다.**

코멘트를 활용하면 별도의 메신저 없이도 **해당 업무와 관련된 내용을 한 곳에서 확인**할 수 있습니다.

---

## 1. 코멘트를 남길 업무 선택

GitHub의 **Projects** 화면으로 이동합니다.

프로젝트 보드에서 코멘트를 작성하려는 **업무 카드를 클릭**합니다.

예시:

- 로그인 화면 수정
- 대시보드 그래프 오류 수정
- 센서 데이터 확인
- 모바일 앱 알림 기능 추가

---

## 2. 업무 상세 화면 열기

업무 카드를 클릭하면 해당 업무의 상세 내용을 확인할 수 있습니다.

여기에서 다음과 같은 내용을 확인할 수 있습니다.

- 업무 제목
- 업무 설명
- 담당자
- 진행 상태
- 기존 코멘트
- 첨부 이미지 및 자료

---

## 3. 코멘트 작성하기

업무 상세 화면 아래쪽의 **Add a comment** 또는 코멘트 입력창을 찾습니다.

내용을 입력한 후 **Comment 버튼**을 클릭하면 코멘트가 등록됩니다.

### 작성 예시

> 해당 부분 확인했습니다.  
> 현재 대시보드에서 그래프가 정상적으로 표시됩니다.

또는

> 모바일에서 확인했을 때 버튼 위치가 조금 어긋나 있습니다.  
> 확인 부탁드립니다.

---

## 4. 이미지 첨부하기

오류 화면이나 수정이 필요한 부분은 **이미지를 함께 첨부하는 것을 권장합니다.**

이미지 파일을 코멘트 입력창에 **드래그해서 넣거나**, 복사한 이미지를 **붙여넣기(Ctrl+V / Command+V)** 할 수 있습니다.

예시:

> 아래 표시한 부분의 글씨가 잘려서 보입니다.  
> 모바일 화면에서도 동일하게 발생합니다.
>
> [화면 캡처 이미지 첨부]

이미지를 함께 첨부하면 담당자가 문제를 훨씬 빠르게 확인할 수 있습니다.

---

## 5. 담당자에게 알림 보내기 (@멘션)

특정 담당자에게 확인을 요청하려면 **@아이디**를 입력합니다.

예시:

> @담당자아이디  
> 해당 내용 확인 부탁드립니다.

`@`를 입력하면 GitHub 사용자 목록이 표시되므로 해당 담당자를 선택하면 됩니다.

멘션된 담당자에게는 GitHub 알림이 전달될 수 있습니다.

---

## 6. 좋은 코멘트 작성 방법

코멘트는 가능한 한 **짧고 명확하게** 작성합니다.

다음 내용을 포함하면 담당자가 확인하기 쉽습니다.

- 무엇을 확인했는지
- 어떤 문제가 있는지
- 어디에서 문제가 발생했는지
- 원하는 수정 내용
- 필요한 경우 화면 캡처

### 좋은 예시

> 대시보드 → 현장 상세 → 그래프에서 확인했습니다.  
> X축을 선택했는데 Y축 데이터도 같이 표시됩니다.  
> X축 선택 시 X축 데이터만 표시되도록 확인 부탁드립니다.
>
> [화면 캡처 첨부]

### 확인하기 어려운 예시

> 그래프 이상합니다. 확인해주세요.

가능하면 **어디에서 / 무엇을 했을 때 / 어떤 문제가 발생했는지** 작성해주세요.

---

## 7. 수정 완료 후 확인

담당자가 수정 완료 코멘트를 남기면 해당 내용을 확인합니다.

정상적으로 수정되었다면 간단하게 확인 결과를 남겨주세요.

예시:

> 수정된 내용 확인했습니다. 정상적으로 동작합니다.

문제가 계속 발생한다면 새로운 업무를 만들기보다 기존 코멘트에 이어서 내용을 작성하면 기존 작업 내역을 함께 확인할 수 있습니다.

---

## 코멘트 작성 예시

**오류 발견**

> 대시보드 현장 상세 화면에서 그래프가 표시되지 않습니다.  
> 새로고침해도 동일합니다.
>
> [화면 캡처 첨부]
>
> @담당자아이디 확인 부탁드립니다.

**수정 요청**

> 현재 버튼명이 `저장하기`로 되어 있습니다.  
> `저장`으로 변경 부탁드립니다.

**수정 확인**

> 수정된 내용 확인했습니다.  
> 정상적으로 동작합니다.

---

## 핵심 정리

**업무 카드 클릭 → 코멘트 작성 → 필요한 경우 이미지 첨부 → 담당자 @멘션 → Comment 클릭**

코멘트에는 가능한 한 **문제가 발생한 위치와 현상을 구체적으로 작성**해주세요.

업무와 관련된 추가 내용은 메신저보다 해당 업무의 코멘트에 남기면 **작업 이력을 한 곳에서 관리하기 편리합니다.**
