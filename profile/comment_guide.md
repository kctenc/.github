# 💬 GitHub Project 코멘트 작성 가이드

Project 코멘트는 **현재 진행 중인 작업에 수정·보완사항이나 추가 요청사항을 전달할 때** 사용합니다.

> 💡 새로운 기능이나 현재 작업과 관계없는 새로운 요청사항이라면 코멘트가 아니라 **새로운 Issue를 등록**해주세요.

---

# 1. GitHub Projects 접속

GitHub의 **Projects** 화면으로 이동합니다.

Project에는 현재 진행 중인 작업들이 카드 형태로 표시됩니다.

---

# 2. 해당 작업 찾기

수정하거나 추가로 요청할 작업을 찾습니다.

예를 들어 현재 아래와 같은 작업이 진행 중이라고 가정합니다.

> `대시보드 그래프 X/Y축 선택 기능 추가`

해당 작업 카드를 클릭합니다.

---

# 3. 기존 작업 내용 확인

코멘트를 작성하기 전에 기존 작업의 제목과 내용을 확인해주세요.

내가 요청하려는 내용이 **현재 작업과 관련된 내용인지 먼저 확인**합니다.

### 코멘트에 작성하는 경우

- 현재 개발 중인 기능의 수정
- 작업 결과 확인 후 수정 요청
- 디자인 변경
- 기존 요청사항에 내용 추가
- 테스트 후 발견된 보완사항
- 담당자에게 추가 자료 전달
- 기존 작업과 관련된 질문

### 새로운 Issue를 만들어야 하는 경우

- 기존 작업과 관계없는 새로운 기능
- 완전히 새로운 화면 개발
- 별도의 개발이 필요한 새로운 요청
- 다른 기능에서 새롭게 발견된 오류

---

# 4. 코멘트 작성

작업 상세 화면에서 **Add a comment** 또는 코멘트 입력창을 찾습니다.

수정하거나 추가로 요청하려는 내용을 작성합니다.

### 예시

현재 작업:

> `대시보드 그래프 X/Y축 선택 기능 추가`

추가 요청:

> X/Y축 선택 기능 확인했습니다.
>
> 추가로 마지막에 선택했던 축이 유지되도록 수정 부탁드립니다.

이처럼 **어떤 부분을 확인했고 무엇을 추가로 수정해야 하는지** 작성해주세요.

---

# 5. 수정 요청은 구체적으로 작성

단순히 "수정해주세요"라고 작성하면 담당자가 어떤 부분을 수정해야 하는지 다시 확인해야 합니다.

가능하면 **현재 상태와 원하는 결과**를 같이 작성해주세요.

### 👍 좋은 예시

> 현장 상세 화면에서 확인했습니다.
>
> 현재 X축을 선택한 후 다른 화면으로 이동했다가 돌아오면 다시 X/Y 전체 보기로 변경됩니다.
>
> 마지막으로 선택했던 X축 상태가 유지되도록 수정 부탁드립니다.

### 👎 피해야 할 예시

> 이거 이상합니다.

> 다시 수정해주세요.

> 안돼요.

---

# 6. 이미지 첨부

화면이나 디자인과 관련된 수정 요청은 가능하면 **화면 캡처를 첨부해주세요.**

특히 수정해야 하는 위치를 이미지에 표시하면 요청 내용을 빠르게 확인할 수 있습니다.

이미지는 다음 방법으로 첨부할 수 있습니다.

- 이미지 파일 드래그
- 복사한 이미지 붙여넣기
- Windows : `Ctrl + V`
- Mac : `Command + V`

### 예시

> 아래 이미지에서 표시한 버튼의 위치를 오른쪽으로 이동해주세요.
>
> `[화면 캡처 첨부]`

---

# 7. 담당자에게 알림 보내기

특정 담당자의 확인이 필요한 경우 `@아이디`를 사용합니다.

예시:

> @담당자아이디
>
> 위 내용 추가 확인 부탁드립니다.

`@`를 입력하면 GitHub 사용자 목록이 표시되므로 해당 담당자를 선택하면 됩니다.

---

# 8. 수정 완료 후 확인

담당자가 작업 완료 또는 수정 완료 코멘트를 작성하면 실제 화면에서 결과를 확인해주세요.

정상적으로 수정되었다면 확인 결과를 코멘트로 남겨주세요.

### 정상인 경우

> 수정된 내용 확인했습니다.  
> 정상적으로 동작합니다.

### 추가 수정이 필요한 경우

> 수정된 내용 확인했습니다.
>
> PC에서는 정상적으로 동작하지만 모바일에서는 버튼이 화면 밖으로 나가는 문제가 있습니다.
>
> 모바일 화면도 추가 확인 부탁드립니다.
>
> `[화면 캡처 첨부]`

같은 작업과 관련된 내용이라면 **새로운 Issue를 만들지 않고 기존 작업의 코멘트에 이어서 작성**합니다.

---

# ✏️ 간단한 코멘트 작성 양식

어떻게 작성해야 할지 모르겠다면 아래 형식을 사용해주세요.

> **확인 내용**  
> 대시보드 현장 상세 화면에서 확인했습니다.
>
> **현재 상태**  
> X축 선택 기능은 정상적으로 동작합니다.
>
> **추가 요청사항**  
> 화면을 다시 접속해도 마지막으로 선택한 X축 상태가 유지되었으면 좋겠습니다.
>
> **참고 이미지**  
> 필요한 경우 화면 캡처 첨부

# 📌 핵심 정리

**진행 중인 작업의 수정·보완**

`GitHub Projects 접속`  
↓  
`진행 중인 작업 찾기`  
↓  
`작업 카드 선택`  
↓  
`Comment 작성`  
↓  
`필요한 경우 이미지 첨부`  
↓  
`담당자 확인`

> **기존 작업과 관련된 수정·보완 → Project 코멘트**
>
> **기존 작업과 관계없는 새로운 요청 → 새로운 Issue**
